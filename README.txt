ImageUpscale (local server edition)

Double-click "Start ImageUpscale.bat". Your browser opens to the app.

Everything runs on this computer. The server only accepts connections from this computer (127.0.0.1).
Nothing is uploaded. The only download is the optional Quality model (64 MB) from huggingface.co.
If a firewall asks about "Node.js" or "node.exe", it is safe to choose Cancel / Block: it only needs to talk to your own browser.
To stop: close the black window (or press Ctrl+C).
Not code-signed, so Windows SmartScreen may warn about the .bat the first time: More info, Run anyway.
Port 4317 busy? Open a Command Prompt here and run: set PORT=4400 && "Start ImageUpscale.bat"
